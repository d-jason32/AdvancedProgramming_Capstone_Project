Frontend (What the User Sees)
Splash Page
 The first screen that appears when the app is opened. It shows the app’s logo and a welcome message as a quick introduction.
Login Page
 A screen where teachers and students sign in using a username and password. This ensures that only authorized users can join a class.
Main Application
 After logging in, the main part of the app is shown. This area allows users to start or join a class and access features like the whiteboard and video chat.
Whiteboard Feature
 A digital board where everyone in the class can draw, write, or type. Tools such as markers, pencils, an eraser, and text boxes are available for sharing ideas in real time.

Backend (What Works Behind the Scenes)
User Authentication
 A process that checks if a person is allowed to use the app by verifying usernames and passwords to keep the system secure.
Session Management
Controls live class sessions and ensures that only the right people join by using a unique class code.
Data Storage
 All information—such as whiteboard drawings, chat messages, and lesson summaries—is stored securely for future access.
Video & Chat System
 Allows users to communicate in real-time through video calls or text messages, helping them share ideas and ask questions during a class.
ChatGPT or Gemini Integration
 After a class ends, the ChatGPT or Gemini reviews the whiteboard content and chat messages to create a simple summary report of the lesson.
Real-Time Translation
 Listens to what is being said during a class and instantly converts the speech into text in other languages, helping users who speak different languages understand the lesson.


User interface: 
Focuses on creating an attractive, easy-to-navigate, and enjoyable look for the app.


Tech Stack: 
JavaFX is used for building the app’s visual parts (front end).
Microsoft Azure handles backend work like data storage and session management.
ChatGPT API OR GEMINI API is used to create lesson summaries.
